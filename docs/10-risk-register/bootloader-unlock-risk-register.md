# Bootloader Unlock Risk Register

## Current status

Bootloader unlock is not approved.

## Risks

| Risk | Status | Mitigation |
| --- | --- | --- |
| Full data wipe | Active | Back up phone and document acceptance before unlock |
| Security reduction | Active | Keep unlock blocked until final decision record |
| Data leakage exposure | Active | Avoid unlocking unless project benefit outweighs risk |
| Warranty or service impact | Active | Document Xiaomi support language and user acceptance |
| Boot failure | Active | Preserve stock fastboot ROM and rollback plan |
| Anti-rollback conflict | Active | Reconfirm anti-rollback value before any flash |
| Region or account eligibility failure | Active | Document Xiaomi Community and account requirements |
| Xiaomi wait period | Active | Treat wait period as blocking until complete |
| Single physical device | Active | Require rollback plan and minimal first test target |
| Relock brick risk | Active | Do not relock after modified images |
| Unsupported ROM compatibility | Active | No ROM or GSI flash without separate decision |
| Unofficial unlock tooling risk | Active | Use only official Xiaomi process if unlock is ever approved |
| Incomplete backup risk | Active | Validate recovery of important accounts and data first |

## Current decision

No-go for unlock. Research and planning only.
