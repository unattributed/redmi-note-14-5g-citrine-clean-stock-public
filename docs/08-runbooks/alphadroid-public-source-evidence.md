# AlphaDroid Public Source Evidence Runbook

This runbook is research only. It does not unlock, flash, erase, install DSU, sideload Google apps, bind a Xiaomi account, or modify the phone.

## Purpose

Collect public source pages for AlphaDroid and Google trust constraints so the project can decide whether AlphaDroid is a credible functional phone candidate or a blocked path.

## Allowed

- Fetch public source pages.
- Capture response headers and HTML.
- Extract non-secret keywords.
- Archive evidence outside the phone.

## Not allowed

- Downloading or flashing ROM artifacts.
- Unlocking the bootloader.
- Running Xiaomi flash scripts.
- Erasing userdata.
- Sideloading Google apps.
- Installing DSU or GSI images.

## Output

Upload the generated evidence bundle named:

```text
citrine-alphadroid-source-evidence-YYYYMMDD-HHMMSS.tar.gz
```
