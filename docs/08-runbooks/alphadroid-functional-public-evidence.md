# AlphaDroid Functional Public Evidence Runbook

This runbook is research only. It does not install AlphaDroid or modify the phone.

## Allowed

- Capture public project pages.
- Capture public release pages.
- Capture official Google documentation relevant to Google trust constraints.
- Search captured public pages for functional phone, Google trust, and downgrade-risk indicators.
- Record non-secret evidence only.

## Not allowed

- Bootloader unlock.
- Flashing.
- Downgrade.
- Formatting userdata.
- Installing DSU or GSI images.
- Sideloading Google applications.
- Downloading ROM ZIP bodies or image bodies as part of this evidence step.
- Relocking.

## Functional evidence needed

The project needs candidate-specific evidence for modem, cellular data, IMS, VoLTE, VoWiFi, emergency calling risk, Wi-Fi, Bluetooth, GNSS, cameras, audio, microphones, sensors, USB, charging, battery, suspend, thermal, Vulkan, GPU, and rollback behavior.

## Google trust evidence needed

The project needs candidate-specific evidence for Google Play Store behavior, Play Protect certification behavior, Play Integrity behavior, sensitive application compatibility, and whether any Google application distribution path is legitimate and supportable.

## Current rule

No bootloader unlock, downgrade, or flashing is approved by this runbook.
